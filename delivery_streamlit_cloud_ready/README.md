# 군포 라스트마일 배송 계획 시뮬레이터

원본 프로젝트의 Python 앱 코드는 변경하지 않은 Streamlit Community Cloud 배포용 패키지입니다.

## 배포
1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 **안에 있는 파일들**(`app.py`, `requirements.txt`, `nodes_original.csv` 등)을 저장소 최상위에 업로드합니다. ZIP 자체를 업로드하지 않습니다.
3. https://share.streamlit.io 에서 GitHub를 연동하고 **Create app**을 누릅니다.
4. 저장소/브랜치를 선택하고 **Main file path**에 `app.py`를 입력합니다.
5. Python 버전은 3.12를 권장합니다. 배포 후 첫 실행에서 라이브러리가 설치됩니다.
6. 생성된 `*.streamlit.app` 주소를 공유할 수 있습니다.

## 기능 테스트
- 대시보드가 열리는지 확인합니다.
- '현재 조건으로 최적화 실행'을 눌러 OSRM 행렬 조회, OR-Tools 계산, Folium 경로 지도가 동작하는지 검증합니다.
- 두 번 실행한 후 결과 비교 표와 그래프를 확인합니다.

## 주의사항
- 외부 OSRM 공개 데모 서비스는 요청 한도와 연결 실패 가능성이 있어 발표 전 테스트가 필요합니다.
- 실행 기록과 편집 데이터는 Streamlit 브라우저 세션에 보관됩니다. 필요한 데이터는 CSV/JSON으로 다운로드하세요.
- AI API 모드는 Gemini API 키와 모델 ID를 별도로 입력해야 합니다. API 키를 GitHub 파일에 적거나 커밋하지 마세요.
- 이 패키지는 **웹 배포 준비용**이며 클라우드에서 실제 작동 여부를 아직 검증한 것은 아닙니다.
- 원본 코드가 사용하는 외부 지도 API 및 서비스 조건을 준수하세요.
